# FamilyCloud — семейное облако на своих дисках

```
 Телефон (приложение)  ──HTTPS + WireGuard (Tailscale)──▶  Компьютер (сервер)
   • загрузка по Wi-Fi                                       • D:\FamilyCloud\<пользователь>\<год>\<месяц>\
   • докачка после обрыва                                    • E:\FamilyCloud\…  — полная копия на 2-м диске
   • раз в месяц: «Освободить место»                         • проверка SHA-256, самовосстановление
```

## Как обеспечена сохранность данных

1. **Контрольная сумма SHA-256.** Телефон считает хеш файла и передаёт его серверу. Сервер после загрузки пересчитывает хеш сам. Если хеши не совпали, файл не принимается и загружается заново.
2. **Две копии на разных физических дисках.** Копия на второй диск записывается во временный файл, сверяется по хешу и только потом ставится на место.
3. **Телефон ничего не удаляет без подтверждения.** Перед удалением приложение дважды спрашивает сервер (при планировании и прямо перед удалением). Удаляются только файлы, которые лежат **на обоих дисках** и не менялись на телефоне после загрузки.
4. **Ничего не перезаписывается.** Если имя совпало, к нему добавляется кусок хеша (`IMG_0001_8b1653c6.JPG`). Повреждённые копии не удаляются, а переименовываются в `*.corrupt-…`.
5. **Атомарная запись и fsync.** Сбой питания посреди записи не портит уже сохранённые файлы. Незавершённая загрузка просто продолжится с места обрыва.
6. **Самовосстановление (scrub).** Раз в месяц сервер перечитывает все файлы. Если одна копия испорчена (например, «битый» сектор), она восстанавливается из второй.
7. **База данных копируется на второй диск** каждые 15 минут. Даже если базы нет совсем, файлы лежат в обычных папках и открываются проводником.
8. Повторы не занимают место: один и тот же файл (по хешу) у пользователя хранится один раз.

## Как обеспечена безопасность

- **Сервер недоступен из интернета.** Он слушает только 127.0.0.1, а снаружи его выставляет Tailscale: шифрование WireGuard и доступ только с ваших устройств. Порты на роутере открывать не нужно.
- **HTTPS с настоящим сертификатом** (`tailscale serve`). Приложение отказывается работать по http.
- **Пароли хранятся как Argon2id.** После 5 ошибок вход блокируется на 15 минут, защита есть и по логину, и по IP.
- **Отдельный токен у каждого устройства.** В базе хранится только его хеш. Потерянный телефон отключается одной командой: `python cli.py revoke <id>`.
- **Изоляция пользователей:** никто не видит и не скачивает чужие файлы. Попытки выйти из своей папки через `../` блокируются.
- На телефоне токен лежит в Keychain / Android Keystore. Есть вход по отпечатку или Face ID.
- **Журнал безопасности:** `python cli.py audit` показывает входы, ошибки и удаления.
- **Рекомендуется:** включите BitLocker на обоих дисках. Тогда при краже компьютера или дисков файлы не прочитать.

## 1. Установка сервера (Windows)

1. Установите **Python 3.11+** с python.org и отметьте «Add to PATH».
2. Распакуйте папку `server` в любое место, например `C:\FamilyCloud\server`.
3. Откройте PowerShell в этой папке и выполните:
   ```powershell
   python -m venv .venv
   .venv\Scripts\pip install -r requirements.txt
   copy config.example.toml config.toml
   notepad config.toml        # укажите primary = "D:/FamilyCloud", mirror = "E:/FamilyCloud"
   ```
4. Создайте пользователей:
   ```powershell
   .venv\Scripts\python cli.py adduser alibek --admin
   .venv\Scripts\python cli.py adduser aigerim
   ```
5. Запуск: `start.bat`. Для автозапуска добавьте `start.bat` в Планировщик заданий с триггером «При входе в систему» или «При запуске». Можно также сделать из него службу через NSSM.

## 2. Доступ с телефона (Tailscale)

1. Установите Tailscale на компьютер (tailscale.com/download) и войдите в аккаунт.
2. В админке Tailscale включите **MagicDNS** и **HTTPS Certificates** (раздел DNS).
3. На компьютере выполните:
   ```powershell
   tailscale serve --bg 8080
   ```
   Команда выведет адрес вида `https://имя-пк.tailXXXX.ts.net`. Его вы введёте в приложении.
4. Установите Tailscale на телефоны членов семьи и войдите в тот же аккаунт. Другой вариант — пригласить их в свою сеть (tailnet).

## 3. Сборка приложения для Android

### Способ А — в облаке GitHub (проще, ничего не ставить)
1. Создайте **приватный** репозиторий на github.com и загрузите в него всю папку `familycloud`. Можно перетащить файлы в браузере, но папку `.github` нужно загрузить тоже.
2. Откройте вкладку **Actions**: сборка запустится сама (примерно 10 минут). Если не запустилась, выберите «Android APK» → **Run workflow**.
3. Скачайте файл в последнем запуске: **Artifacts → FamilyCloud-apk**. Внутри zip лежит `app-release.apk`.

**Постоянный ключ подписи** (рекомендуется). Без него каждое обновление придётся ставить только после удаления старой версии приложения:
```powershell
keytool -genkeypair -keystore familycloud.jks -alias familycloud -keyalg RSA -keysize 4096 -validity 10000 -dname "CN=FamilyCloud, C=KZ"
[Convert]::ToBase64String([IO.File]::ReadAllBytes("familycloud.jks")) | Set-Clipboard
```
В репозитории откройте Settings → Secrets and variables → Actions и добавьте два секрета: `KEYSTORE_BASE64` (вставьте из буфера) и `KEYSTORE_PASSWORD` (пароль, который вы ввели). Сам файл `familycloud.jks` храните в надёжном месте.

### Способ Б — на своём компьютере
1. Установите **Android Studio**, затем **Flutter** (docs.flutter.dev → Windows → Android). В конце `flutter doctor` должен показать галочку у Android toolchain.
2. В папке `mobile` выполните:
   ```powershell
   powershell -ExecutionPolicy Bypass -File build_android.ps1
   ```
   Скрипт сам создаст проект, настроит разрешения и ключ подписи и соберёт `mobile\FamilyCloud.apk`.
3. Файлы `familycloud-release.jks` и `keystore-password.txt` сохраните в надёжном месте: без них не получится выпустить обновление.

### Установка на телефон
1. Скопируйте APK на телефон (через кабель, Telegram «Избранное» или Google Диск) и откройте его. Разрешите «Установка из неизвестных источников» для этого приложения.
2. Установите **Tailscale** из Google Play и войдите в свой аккаунт. В настройках Android откройте Сеть → VPN → Tailscale и включите **«Постоянная VPN»**. Без этого фоновая загрузка не дойдёт до сервера.
3. Откройте FamilyCloud и введите адрес `https://имя-пк.tailXXXX.ts.net`, логин и пароль.
4. Разрешите доступ **ко всем** фото и видео. При выборе «только выбранные» остальные файлы не выгрузятся.
5. Чтобы система не «усыпляла» фоновую загрузку, откройте Настройки → Приложения → FamilyCloud → Батарея и выберите **«Без ограничений»**. На Xiaomi, Samsung и Huawei также включите **«Автозапуск»**.

## 4. Как этим пользоваться

- Приложение само загружает новые фото и видео каждые ~6 часов. Условия: есть Wi-Fi и заряд батареи не низкий. Кнопка «Загрузить сейчас» запускает загрузку сразу.
- Раз в месяц приходит уведомление. Откройте приложение и нажмите **«Освободить место»**. Приложение догрузит новое, проверит файлы на сервере, покажет, сколько освободится, и попросит подтверждение (системное окно Android/iOS).
- На iPhone после этого очистите альбом «Недавно удалённые».
- Порог «старше 30 дней» меняется в настройках: 30, 60, 90 или 180 дней.

## 5. Обслуживание

| Команда | Что делает |
|---|---|
| `python cli.py users` | пользователи и объём их файлов |
| `python cli.py devices` | все подключённые телефоны |
| `python cli.py revoke 3` | отключить телефон №3 (потерян/украден) |
| `python cli.py passwd aigerim` | сменить пароль (все её устройства выйдут) |
| `python cli.py scrub` | полная проверка всех файлов + восстановление |
| `python cli.py audit 100` | журнал безопасности |

Добавьте `scrub.bat` в Планировщик заданий **раз в месяц** (ночью). Результат пишется в `scrub.log`. Если там `"lost"` > 0, значит повреждены обе копии файла. Такое возможно, только если оба диска испортились одновременно.

## 6. Важно знать

- **Два диска не заменяют резервную копию от пожара, кражи или вируса-шифровальщика.** Для действительно ценного раз в квартал копируйте папку на внешний диск и храните его в другом месте.
- iOS и Android не дают удалять фото молча: подтверждение пользователя обязательно, это защита самой системы.
- На iPhone с включёнными «Фото iCloud» удаление на телефоне удалит фото и из iCloud.
- Компьютер должен быть включён, чтобы телефоны могли загружать файлы. Если загрузка не дошла, она продолжится в следующий раз с места обрыва.
- Логи сервера: `D:\FamilyCloud\.familycloud\server.log`.
